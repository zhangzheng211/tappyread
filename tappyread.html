📖 使用说明

📖 概述

tappyread点读机是一款专为英语阅读设计的交互式学习工具，用你的PDF和图片，一分钟制作点读书，我的绘本我做主。——tappyread点读机

🚀 快速入门

使用内置绘本库（推荐新手）
本工具已内置了一套牛津阅读树绘本库，您只需两步即可开始阅读：
第一步：设置图片目录
点击顶部工具栏的 📁 图片目录 按钮，选择您存放绘本图片的文件夹路径（支持U盘、移动硬盘等）。设置后，所有绘本将从此目录加载图片。
第二步：导入绘本目录
点击绘本目录左上角的 📥 导入 按钮，选择随工具提供的 绘本目录备份_xxxx-xx-xx.json 备份文件，导入成功后即可开始阅读初始化的绘本内容了！

📄 PDF转图片工具

点击顶部工具栏的 📄 PDF转图片 按钮，打开独立的PDF转图片工具页面。
功能说明：
  • 支持拖拽或选择多个PDF文件
  • 将PDF每一页转换为高质量JPG图片
  • 自动打包成ZIP文件下载
  • 完全在浏览器本地运行，文件不上传服务器
使用场景：如果您有PDF格式的绘本电子书，可以先用此工具将每一页转换为JPG图片，然后使用「批量导入绘本」功能快速创建绘本。

✨ 创建自己的绘本

第一步：创建绘本
有两种方式创建绘本：
方式操作适用场景
📖 新增绘本点击 📖 新增绘本，输入名称即可创建手动创建单个绘本
📦 批量导入绘本点击 📦 批量导入绘本，选择多张图片自动识别分组从图片文件批量创建多个绘本
批量导入小技巧：将图片按 01-绘本名-01.jpg、01-绘本名-02.jpg 或 绘本名 1.jpg 等格式命名，系统会自动按绘本名称分组，一次导入多个绘本。
第二步：添加页面
选中一个绘本后，点击 ➕ 添加绘本页面，上传图片（支持多选/拖拽），系统会自动识别图片底部的英文文字并填入。您也可以手动编辑修正识别结果。
第三步：开始点读
点击绘本页面上的 🔊 按钮或直接点击图片，即可播放对应的英文朗读。点击页面中的任意单词，可单独朗读该单词。

🎯 核心功能详解

1. 绘本目录管理

功能按钮位置说明
新建文件夹目录区左上角「✨ 新建」创建文件夹，支持3级嵌套。点击「新建」后会弹出选择框，让您决定在根目录还是当前选中的文件夹下创建。
导入备份目录区左上角「📥 导入」恢复之前导出的完整目录备份
导出备份目录区左上角「📤 导出」备份全部目录、绘本、页面文本
搜索目录区搜索框按绘本/文件夹名称模糊搜索
删除/重命名鼠标悬停目录项显示编辑和删除按钮

2. 绘本页面操作

功能操作方式说明
翻页点击 ◀ ▶ 按钮或键盘左右键跨页浏览（双页展示）
点读点击图片或 🔊 按钮朗读该页的英文文字
单词点读点击页面中的任意单词单独朗读该单词
编辑文字点击 ✏️ 按钮修改本页朗读文本
删除页面目录中悬停页面项，点击 ✕删除该页（至少保留1页）

3. 批量导入绘本

使用场景：您有一批按一定规则命名的图片文件，希望快速生成多个绘本。
文件名格式要求： 
01-Kipper's Diary-01.jpg     → 绘本"Kipper's Diary"的第1页
01-Kipper's Diary-02.jpg     → 绘本"Kipper's Diary"的第2页
02-Spaceman-01.jpg           → 绘本"Spaceman"的第1页
支持的命名模式：
  • 数字-绘本名-页码.jpg
  • 绘本名 页码.jpg
  • 数字 绘本名 页码.jpg
操作步骤：
  1. 点击 📦 批量导入绘本
  2. 选择所有图片文件（支持多选）
  3. 系统自动分析并按绘本名称分组
  4. 预览确认每个绘本的页面和名称
  5. 点击「✅ 确认导入」，系统自动识别每页文字并导入

4. OCR文字识别

工作原理：系统会裁剪图片底部约20-30%的区域（通常是白色文字条），使用Tesseract OCR引擎识别英文文字，并自动过滤乱码。
优化建议：
  • 确保图片底部文字清晰、对比度高
  • 支持批量识别，多张图片并发处理
  • 识别完成后可手动编辑修正

5. 单词白名单

点击 📝 单词白名单 管理常用单词列表，系统在OCR识别后会自动保留白名单中的单词，提高识别准确率。
功能：
  • 添加新单词（自动识别复数、过去式等变形）
  • 删除自定义单词
  • 恢复默认白名单

6. 语音朗读设置

设置项说明
音色选择下拉菜单选择不同的语音引擎
语速调节滑动条调整朗读速度（慢→快）

❓ 常见问题

Q1: 图片显示"未找到图片"？
检查 📁 图片目录 路径是否正确，确保图片文件名与绘本页面中记录的文件名一致。
Q2: OCR识别不准确？
  • 确保图片底部文字区域清晰
  • 使用 📝 单词白名单 添加常用单词
  • 识别后可手动编辑修正
Q3: 备份文件导入后图片不显示？
导入备份后，检查 📁 图片目录 是否与备份时的路径一致。如有变化，重新设置图片目录即可。
Q4: 批量导入时识别到乱码？
系统已内置智能乱码过滤，如果仍有乱码，请检查图片底部文字是否清晰，或手动编辑修正。
Q5: 支持哪些图片格式？
支持常见格式：JPG、PNG、BMP、WebP等。
