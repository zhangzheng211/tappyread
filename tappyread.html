📖 使用说明

📖 概述

tappyread点读机是一款专为英语阅读设计的交互式学习工具，用你的PDF和图片，一分钟制作点读书，我的绘本我做主。——tappyread点读机

🚀 快速入门

使用内置绘本库（推荐新手）
本工具已内置了一套牛津阅读树绘本库，您只需两步即可开始阅读：
第一步：设置图片目录
点击顶部工具栏的 📁 图片目录 按钮，选择您存放绘本图片的文件夹路径（支持U盘、移动硬盘等）。设置后，所有绘本将从此目录加载图片。
第二步：导入绘本目录
点击绘本目录左上角的 📥 导入 按钮，选择随工具提供的 绘本目录备份_xxxx-xx-xx.json 备份文件，导入成功后即可开始阅读初始化的绘本内容了！

📄 PDF转图片工具（独立小工具）

点击顶部工具栏的 📄 PDF转图片 按钮，会在新标签页打开一个独立的PDF转图片小工具。
功能说明：
  • 支持拖拽或选择多个PDF文件
  • 将PDF每一页转换为高质量JPG图片
  • 自动打包成ZIP文件下载到本地
  • 完全在浏览器本地运行，文件不上传服务器
这是一个纯本地小工具：如果您只是想把PDF转成图片留着自己用（不需要立即生成绘本），用这个工具最方便。如果您的目的是"把PDF直接做成绘本"，不需要单独用这个工具——请直接使用下面介绍的 📦 PDF批量生成，一步到位。

📦 PDF批量生成（推荐：PDF一键变绘本）

点击顶部工具栏的 📦 PDF批量生成，选择一个或多个PDF文件，系统会自动完成"转图片 → 上传服务器 → 识别文字 → 生成绘本"全部流程，每个PDF自动生成一本对应的绘本，无需再手动操作图片。
完整流程：
  1. 点击 📦 PDF批量生成，弹窗中选择/拖拽一个或多个PDF文件
  2. 点击「🚀 开始转换并生成绘本」，系统按PDF页面顺序把每一页转换为高清JPG图片
  3. 每张图片转换完成后，会立即以图片的形式上传到服务器目录（腾讯云COS的 jpeg/ 目录），全程可在弹窗里看到实时进度和日志
  4. 这一批图片全部上传完成后，系统自动按PDF文件名分组识别每页文字（与「PDF批量生成」原有识别逻辑完全一致），弹出预览列表
  5. 确认无误后点击「✅ 确认导入」，即可批量生成对应的绘本
绘本命名规则：与「PDF转图片」工具保持一致——会自动去掉文件名开头的数字前缀（如 01-）、把下划线换成空格，剩下的部分就是绘本名称；PDF内的页面顺序即为绘本的页面顺序。
图片需要联网上传到服务器，请确保网络畅通；上传过程中请不要关闭弹窗，否则可能中断处理。

✨ 创建自己的绘本

第一步：创建绘本
有两种方式创建绘本：
方式操作适用场景
📖 新增绘本点击 📖 新增绘本，输入名称即可创建手动创建单个空白绘本，自己添加图片
📦 PDF批量生成点击 📦 PDF批量生成，选择一个或多个PDF文件已有PDF格式的绘本电子书，一次批量生成多本绘本
批量生成小技巧：PDF文件名建议按 01-绘本名.pdf、02-绘本名.pdf 这样带数字前缀的方式命名，系统会按数字自动排序；不带数字前缀也可以，此时按文件名排序。
第二步：添加页面
选中一个绘本后，点击 ➕ 添加绘本页面，上传图片（支持多选/拖拽），系统会自动识别图片底部的英文文字并填入。您也可以手动编辑修正识别结果。
第三步：开始点读
点击绘本页面上的 🔊 按钮或直接点击图片，即可播放对应的英文朗读。点击页面中的任意单词，可单独朗读该单词。

3. PDF批量生成

使用场景：您手上有一批PDF格式的绘本电子书，希望一次性快速生成多本绘本，不想再手动逐张处理图片。
PDF文件命名建议： 
01-Kipper's Diary.pdf     → 生成绘本"Kipper's Diary"
02-Spaceman.pdf           → 生成绘本"Spaceman"
Biff and Chip.pdf         → 生成绘本"Biff and Chip"（不带数字前缀也可以）
处理规则：
  • 每个PDF自动生成一本对应的绘本，绘本名取自PDF文件名（自动去掉开头的数字前缀、下划线转空格）
  • PDF内每一页按原有顺序转换为一张图片，即绘本的一页
  • 转换出的图片会自动上传到服务器（腾讯云COS），不再像「PDF转图片」那样只生成本地ZIP
操作步骤：
  1. 点击 📦 PDF批量生成
  2. 选择或拖拽一个或多个PDF文件，点击「🚀 开始转换并生成绘本」
  3. 等待系统逐页转换、逐张上传（可在弹窗中查看实时进度和日志）
  4. 全部图片上传完成后，系统自动分析并按PDF文件名分组，弹出预览
  5. 预览确认每个绘本的页面和名称
  6. 点击「✅ 确认导入」，系统自动识别每页文字并生成绘本

4. OCR文字识别

工作原理：系统会裁剪图片底部约20-30%的区域（通常是白色文字条），使用Tesseract OCR引擎识别英文文字，并自动过滤乱码。
优化建议：
  • 确保图片底部文字清晰、对比度高
  • 支持批量识别，多张图片并发处理
  • 识别完成后可手动编辑修正

5. 单词白名单

点击 📝 单词白名单 管理常用单词列表，系统在OCR识别后会自动保留白名单中的单词，提高识别准确率。
功能：
  • 添加新单词（自动识别复数、过去式等变形）
  • 删除自定义单词
  • 恢复默认白名单

6. 语音朗读设置

设置项说明
音色选择下拉菜单选择不同的语音引擎
语速调节滑动条调整朗读速度（慢→快）

❓ 常见问题

Q1: 图片显示"未找到图片"？
检查 📁 图片目录 路径是否正确，确保图片文件名与绘本页面中记录的文件名一致。
Q2: OCR识别不准确？
  • 确保图片底部文字区域清晰
  • 使用 📝 单词白名单 添加常用单词
  • 识别后可手动编辑修正
Q3: 备份文件导入后图片不显示？
导入备份后，检查 📁 图片目录 是否与备份时的路径一致。如有变化，重新设置图片目录即可。
Q4: 批量导入时识别到乱码？
系统已内置智能乱码过滤，如果仍有乱码，请检查图片底部文字是否清晰，或手动编辑修正。
Q5: 支持哪些图片格式？
支持常见格式：JPG、PNG、BMP、WebP等。
Q6: PDF批量生成时提示图片上传失败？
请检查网络连接是否正常；图片会优先尝试直传腾讯云COS，失败时自动降级走后端中转。个别图片上传失败不影响整体流程，仍会继续转换、识别并生成绘本，可稍后在绘本目录里手动检查对应页面是否需要重新添加图片。
